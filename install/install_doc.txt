# AMuBBS 论坛系统

欢迎使用 AMuBBS！这是一个基于 PHP 8.1+ 的轻量化论坛系统。

## 系统特点

- **轻量高效** - 精简的代码结构，快速响应
- **现代化设计** - 简洁美观的用户界面
- **易于部署** - 一键安装向导，快速上线
- **功能完善** - 支持板块、帖子、用户管理等核心功能

## 环境要求

### 必需组件
- PHP 8.1 或更高版本
- MySQL 5.7+ / MariaDB 10.3+
- PDO 和 PDO_MySQL 扩展
- mbstring 扩展
- JSON 扩展

### 推荐组件
- Redis 扩展（用于缓存加速）
- OPcache 扩展（提升性能）
- 支持 URL Rewrite 的 Web 服务器

## 安装步骤

本安装向导将引导你完成以下步骤：

1. **环境检测** - 自动检查服务器环境是否满足要求
2. **数据库配置** - 配置数据库连接并自动初始化数据表
3. **管理员账号** - 创建论坛管理员账号
4. **站点设置** - 配置站点名称、描述等基本信息
5. **完成安装** - 生成配置文件，开始使用

## 注意事项

- 请确保 `config/`、`storage/logs/`、`storage/cache/`、`install/` 目录可写
- 安装完成后，系统会自动生成 `install.lock` 锁文件防止重复安装
- 如需重新安装，请手动删除 `install/install.lock` 文件
