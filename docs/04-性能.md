# 性能优化方案

## 4.1 性能优化目标

### 4.1.1 响应时间目标
- **首页加载**：< 50ms（OPcache + Redis 缓存）
- **板块列表**：< 80ms（含 20 条帖子）
- **帖子详情**：< 100ms（含 50 条回复）
- **发帖操作**：< 150ms（含敏感词过滤）
- **搜索功能**：< 200ms（全文搜索）

### 4.1.2 并发性能目标
- **QPS**：2000+（4C8G 服务器）
- **并发连接**：500-2000
- **数据库连接池**：50-100 连接

### 4.1.3 资源使用目标
- **CPU 使用率**：< 70%（正常负载）
- **内存使用率**：< 80%
- **数据库响应**：< 10ms（单次查询）
- **Redis 响应**：< 1ms

## 4.2 多级缓存体系

### 4.2.1 缓存层级设计

```
┌─────────────────────────────────────────────────────────┐
│  Level 1: 进程内缓存（PHP 变量）                          │
│  - 生命周期：单次请求                                     │
│  - 容量：无限制（受内存限制）                              │
│  - 命中率：最高                                           │
│  - 适用：同一请求内的重复查询                              │
└─────────────────────────────────────────────────────────┘
                            ↓ Miss
┌─────────────────────────────────────────────────────────┐
│  Level 2: OPcache（PHP 字节码缓存）                       │
│  - 生命周期：进程级别                                     │
│  - 容量：128MB-512MB                                     │
│  - 命中率：99%+                                          │
│  - 适用：PHP 文件编译结果                                 │
└─────────────────────────────────────────────────────────┘
                            ↓ Miss
┌─────────────────────────────────────────────────────────┐
│  Level 3: Redis 缓存（内存 KV 存储）                      │
│  - 生命周期：可配置（秒-天）                              │
│  - 容量：1GB-8GB                                         │
│  - 命中率：80-95%                                        │
│  - 适用：热点数据、会话、计数器                            │
└─────────────────────────────────────────────────────────┘
                            ↓ Miss
┌─────────────────────────────────────────────────────────┐
│  Level 4: MySQL 查询缓存（MySQL 5.7）                     │
│  - 生命周期：数据变更前                                   │
│  - 容量：128MB-512MB                                     │
│  - 命中率：50-70%                                        │
│  - 适用：只读查询                                         │
└─────────────────────────────────────────────────────────┘
                            ↓ Miss
┌─────────────────────────────────────────────────────────┐
│  Level 5: 数据库（持久化存储）                            │
│  - 响应时间：5-50ms                                      │
│  - 适用：所有数据                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.2.2 缓存策略实现

#### 页面级缓存
```php
<?php
// 首页缓存（5分钟）
$cacheKey = 'page:index';
$html = Cache::get($cacheKey, function() {
    return renderHomePage();
}, 300);

echo $html;
```

#### 数据级缓存
```php
<?php
// 帖子详情缓存（10分钟）
$cacheKey = "thread:detail:{$threadId}";
$thread = Cache::get($cacheKey, function() use ($threadId) {
    return Database::fetchOne("SELECT * FROM threads WHERE id = ?", [$threadId]);
}, 600);
```

#### 查询结果缓存
```php
<?php
// 板块帖子列表缓存（5分钟）
$cacheKey = "thread:list:{$forumId}:{$page}";
$threads = Cache::tags(['thread', "forum:{$forumId}"])->get($cacheKey, function() use ($forumId, $page) {
    return ThreadRepository::getByForumId($forumId, ($page - 1) * 20, 20);
}, 300);
```

#### 计数器缓存（延迟写入）
```php
<?php
// 浏览次数计数器
function incrementThreadViews(int $threadId): void
{
    $key = "thread:views:{$threadId}";

    // Redis 计数器
    $views = Cache::getRedis()->incr($key);

    // 每 100 次同步到数据库
    if ($views % 100 === 0) {
        Database::execute(
            "UPDATE threads SET views = views + 100 WHERE id = ?",
            [$threadId]
        );
        Cache::getRedis()->decrBy($key, 100);
    }
}
```

### 4.2.3 缓存失效策略

#### 主动失效
```php
<?php
// 发帖后清除相关缓存
function afterThreadCreated(int $threadId, int $forumId): void
{
    // 清除板块相关缓存
    Cache::tags(["forum:{$forumId}"])->flush();

    // 清除首页缓存
    Cache::delete('page:index');

    // 清除用户帖子列表缓存
    Cache::deletePattern("user:threads:*");
}
```

#### 被动失效（TTL）
```php
<?php
// 不同数据的 TTL 策略
$ttlConfig = [
    'hot_threads' => 60,        // 热门帖子：1分钟
    'thread_list' => 300,       // 帖子列表：5分钟
    'thread_detail' => 600,     // 帖子详情：10分钟
    'user_info' => 1800,        // 用户信息：30分钟
    'forum_list' => 3600,       // 板块列表：1小时
    'settings' => 86400,        // 系统配置：1天
];
```

#### 缓存预热
```php
<?php
// 系统启动时预热热点数据
function warmupCache(): void
{
    // 预热板块列表
    $forums = Database::fetchAll("SELECT * FROM forums ORDER BY rank");
    Cache::set('forum:list', $forums, 3600);

    // 预热热门帖子
    $hotThreads = Database::fetchAll(
        "SELECT * FROM threads ORDER BY views DESC LIMIT 100"
    );
    Cache::set('thread:hot', $hotThreads, 300);

    // 预热系统配置
    $settings = Database::fetchAll("SELECT * FROM settings");
    foreach ($settings as $setting) {
        Cache::set("setting:{$setting['key']}", $setting['value'], 86400);
    }
}
```

## 4.3 数据库优化

### 4.3.1 查询优化

#### 避免 SELECT *
```php
<?php
// ❌ 不推荐
$thread = Database::fetchOne("SELECT * FROM threads WHERE id = ?", [$id]);

// ✅ 推荐
$thread = Database::fetchOne(
    "SELECT id, title, user_id, views, posts, created_at FROM threads WHERE id = ?",
    [$id]
);
```

#### 使用索引覆盖
```php
<?php
// 查询只需要索引中的字段，避免回表
$sql = "
    SELECT id, title, last_post_time
    FROM threads
    WHERE forum_id = ? AND deleted_at IS NULL
    ORDER BY is_top DESC, last_post_time DESC
    LIMIT 20
";
// 索引：KEY `idx_threads_forum_id` (`forum_id`, `is_top`, `last_post_time`, `id`, `title`)
```

#### 分页优化（延迟关联）
```php
<?php
// ❌ 传统分页（深分页性能差）
$sql = "SELECT * FROM threads WHERE forum_id = ? LIMIT 1000, 20";

// ✅ 延迟关联优化
$sql = "
    SELECT t.*
    FROM threads t
    INNER JOIN (
        SELECT id FROM threads
        WHERE forum_id = ?
        ORDER BY last_post_time DESC
        LIMIT 1000, 20
    ) AS tmp ON t.id = tmp.id
";
```

#### 批量查询优化
```php
<?php
// ❌ N+1 查询问题
foreach ($threads as $thread) {
    $user = Database::fetchOne("SELECT * FROM users WHERE id = ?", [$thread['user_id']]);
    $thread['user'] = $user;
}

// ✅ 批量查询
$userIds = array_column($threads, 'user_id');
$users = Database::fetchAll(
    "SELECT * FROM users WHERE id IN (" . implode(',', $userIds) . ")"
);
$userMap = array_column($users, null, 'id');

foreach ($threads as &$thread) {
    $thread['user'] = $userMap[$thread['user_id']] ?? null;
}
```

### 4.4.3 代码优化技巧

#### 使用类型声明
```php

// PHP 8.2+ 类型优化

{
    return Database::fetchOne("SELECT * FROM threads WHERE id = ?", [$id]);
}
```

#### 避免重复计算
```php
<?php
// ❌ 不推荐

    // count() 每次循环都会执行

// ✅ 推荐

for ($i = 0; $i < $count; $i++) {
    // ...
}
```

#### 使用生成器节省内存
```php
<?php
// ❌ 一次性加载所有数据
function getAllThreads(): array
{
    return Database::fetchAll("SELECT * FROM threads");
}

// ✅ 使用生成器逐条返回
function getAllThreads(): Generator
{
    $stmt = Database::getConnection()->query("SELECT * FROM threads");
    while ($row = $stmt->fetch()) {
        yield $row;
    }
}
```

#### 字符串优化
```php
<?php

}

// ✅ 使用数组 + implode

foreach ($threads as $thread) {
    $parts[] = "<div>{$thread['title']}</div>";
}
$html = implode('', $parts);
```

#### 防抖与节流
```javascript
// 防抖：搜索输入
function debounce(func, wait) {
    let timeout;
    return function(...args) {
        clearTimeout(timeout);
        timeout = setTimeout(() => func.apply(this, args), wait);
    };
}

const searchInput = document.getElementById('search');
searchInput.addEventListener('input', debounce(function(e) {
    performSearch(e.target.value);
}, 300));

// 节流：滚动加载
function throttle(func, limit) {
    let inThrottle;
    return function(...args) {
        if (!inThrottle) {
            func.apply(this, args);
            inThrottle = true;
            setTimeout(() => inThrottle = false, limit);
        }
    };
}

window.addEventListener('scroll', throttle(function() {
    checkLoadMore();
}, 200));
```

### 4.6.2 站点配置

```nginx
# /etc/nginx/sites-available/amubbs
server {
    listen 80;
    server_name amubbs.com;
    root /var/www/amubbs/public;
    index index.php index.html;

    # 访问日志
    access_log /var/log/nginx/amubbs_access.log main;
    error_log /var/log/nginx/amubbs_error.log;

    # 静态资源缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff|woff2|ttf)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # PHP 处理
    location ~ \.php$ {
        try_files $uri =404;
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;

        # FastCGI 缓存（仅 GET 请求）
        fastcgi_cache PHPCACHE;
        fastcgi_cache_valid 200 5m;
        fastcgi_cache_methods GET;
        fastcgi_cache_bypass $http_pragma $http_authorization;
        add_header X-Cache-Status $upstream_cache_status;
    }

    # URL 重写
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # 禁止访问隐藏文件
    location ~ /\. {
        deny all;
        access_log off;
        log_not_found off;
    }
}
```

## 4.8 性能监控

### 4.8.1 监控指标

```php
<?php
// app/Middlewares/PerformanceMonitor.php

class PerformanceMonitor
{
    private float $startTime;
    private int $startMemory;

    public function before(): void
    {
        $this->startTime = microtime(true);
        $this->startMemory = memory_get_usage();
    }

    public function after(): void
    {
        $duration = (microtime(true) - $this->startTime) * 1000;
        $memory = (memory_get_usage() - $this->startMemory) / 1024 / 1024;

        // 记录慢请求
        if ($duration > 500) {
            error_log(sprintf(
                "[SLOW] %s %s - %.2fms, %.2fMB",
                $_SERVER['REQUEST_METHOD'],
                $_SERVER['REQUEST_URI'],
                $duration,
                $memory
            ));
        }

        // 添加响应头
        header("X-Response-Time: {$duration}ms");
        header("X-Memory-Usage: {$memory}MB");
        header("X-Query-Count: " . count(Database::getQueryLog()));
    }
}
```
