## 🚀 快速开始

### 1. 环境准备

```bash
# 安装 PHP 8.2
sudo apt install php8.2-fpm php8.2-mysql php8.2-redis php8.2-opcache

# 安装 MySQL 8.0
sudo apt install mysql-server-8.0

# 安装 Redis 7.0
sudo apt install redis-server

# 安装 Nginx
sudo apt install nginx

# 安装 Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
```

### 2. 项目初始化

```bash
# 克隆项目
git clone https://github.com/your-repo/amubbs.git
cd amubbs

# 安装依赖
composer install

# 配置数据库
cp config/database.example.php config/database.php
# 编辑 config/database.php 填入数据库信息

# 导入数据库
mysql -u root -p amubbs < install/database.sql

# 配置权限
chmod -R 755 storage/
chmod -R 755 public/uploads/
```

### 3. 配置 Nginx

```nginx
server {
    listen 80;
    server_name amubbs.local;
    root /var/www/amubbs/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

### 4. 配置 PHP

```ini
; /etc/php/8.2/fpm/php.ini

[opcache]
opcache.enable=1
opcache.memory_consumption=256
opcache.interned_strings_buffer=16
opcache.max_accelerated_files=10000
opcache.validate_timestamps=0
opcache.jit_buffer_size=128M
opcache.jit=1255

[PHP]
memory_limit=256M
upload_max_filesize=10M
post_max_size=10M
```

### 5. 启动服务

```bash
# 启动 Nginx
sudo systemctl start nginx

# 启动 PHP-FPM
sudo systemctl start php8.2-fpm

# 启动 Redis
sudo systemctl start redis-server

# 启动 MySQL
sudo systemctl start mysql

# 访问网站
http://amubbs.local
```

## 📝 代码规范

### PHP 代码规范（PSR-12）

```php
<?php

namespace App\Controllers;

use App\Services\ThreadService;

class ThreadController extends BaseController
{
    private ThreadService $threadService;

    public function __construct()
    {
        parent::__construct();
        $this->threadService = new ThreadService();
    }

    /**
     * 帖子列表
     *
     * @return void
     */
    public function index(): void
    {
        $forumId = (int) ($_GET['fid'] ?? 0);
        $page = (int) ($_GET['page'] ?? 1);

        $result = $this->threadService->getThreadList($forumId, $page, 20);

        $this->render('thread/index', $result);
    }
}
```

### JavaScript 代码规范

```javascript
// Alpine.js 组件
function threadList() {
    return {
        threads: [],
        loading: false,
        page: 1,

        async loadThreads() {
            this.loading = true;
            try {
                const response = await fetch(`/api/threads?page=${this.page}`);
                const data = await response.json();
                this.threads = data.data;
            } catch (error) {
                console.error('加载失败:', error);
            } finally {
                this.loading = false;
            }
        }
    }
}
```

## 🐛 常见问题

### Q1: 如何启用 PHP JIT？
```ini
; php.ini
opcache.jit_buffer_size=128M
opcache.jit=1255
```

### Q2: Redis 连接失败？
```bash
# 检查 Redis 是否运行
sudo systemctl status redis-server

# 检查端口
netstat -an | grep 6379

# 测试连接
redis-cli ping
```

### Q3: Nginx 502 错误？
```bash
# 检查 PHP-FPM 是否运行
sudo systemctl status php8.2-fpm

# 检查 PHP-FPM 日志
tail -f /var/log/php8.2-fpm.log

# 检查 Nginx 配置
sudo nginx -t
```

### Q4: 性能达不到目标？
1. 检查 OPcache 是否启用：`php -i | grep opcache`
2. 检查 Redis 是否正常：`redis-cli info stats`
3. 检查慢查询日志：`tail -f /var/log/mysql/slow.log`
4. 使用性能分析工具：Xhprof / Blackfire
