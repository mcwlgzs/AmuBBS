# 数据库设计

## 3.1 数据库设计原则

### 3.1.1 设计理念
- **性能优先**：索引优化、查询优化、避免复杂关联
- **适度冗余**：用空间换时间，减少 JOIN 操作
- **分表策略**：大表分表，历史数据归档
- **缓存友好**：数据结构便于缓存，减少缓存穿透

### 3.1.2 命名规范
- 表名：小写 + 下划线，复数形式（如 `users`, `threads`）
- 字段名：小写 + 下划线（如 `user_id`, `created_at`）
- 索引名：`idx_表名_字段名`（如 `idx_threads_forum_id`）
- 唯一索引：`uk_表名_字段名`（如 `uk_users_email`）

### 3.1.3 字段类型选择
- **主键**：`INT UNSIGNED` 或 `BIGINT UNSIGNED`（自增）
- **时间戳**：`INT UNSIGNED`（Unix 时间戳，节省空间）
- **状态字段**：`TINYINT`（枚举值）
- **计数器**：`INT UNSIGNED`（浏览数、回复数等）
- **文本内容**：`TEXT` 或 `MEDIUMTEXT`（根据长度选择）

## 3.2 核心数据表设计

### 3.2.1 用户表 (users)

```sql
CREATE TABLE `users` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(32) NOT NULL COMMENT '用户名',
  `email` VARCHAR(100) NOT NULL COMMENT '邮箱',
  `password` CHAR(60) NOT NULL COMMENT '密码（bcrypt）',
  `avatar` VARCHAR(255) DEFAULT '' COMMENT '头像URL',
  `group_id` TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '用户组ID',
  `credits` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '积分',
  `threads` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '主题数',
  `posts` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '回复数',
  `login_ip` VARCHAR(45) DEFAULT '' COMMENT '最后登录IP',
  `login_at` INT UNSIGNED DEFAULT 0 COMMENT '最后登录时间',
  `created_at` INT UNSIGNED NOT NULL COMMENT '注册时间',
  `updated_at` INT UNSIGNED DEFAULT 0 COMMENT '更新时间',
  `deleted_at` INT UNSIGNED DEFAULT NULL COMMENT '删除时间（软删除）',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_users_username` (`username`),
  UNIQUE KEY `uk_users_email` (`email`),
  KEY `idx_users_group_id` (`group_id`),
  KEY `idx_users_credits` (`credits`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

**设计说明：**
- `password` 使用 bcrypt 加密，固定 60 字符
- `credits`、`threads`、`posts` 冗余字段，避免频繁统计
- `login_ip` 使用 VARCHAR(45) 支持 IPv6
- 时间字段统一使用 Unix 时间戳（INT UNSIGNED）

### 3.2.3 板块表 (forums)

```sql
CREATE TABLE `forums` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '板块ID',
  `parent_id` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '父板块ID（0为顶级）',
  `name` VARCHAR(64) NOT NULL COMMENT '板块名称',
  `description` VARCHAR(255) DEFAULT '' COMMENT '板块描述',
  `icon` VARCHAR(255) DEFAULT '' COMMENT '板块图标',
  `rank` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '排序权重',
  `threads` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '主题数',
  `posts` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '回复数',
  `moderators` VARCHAR(255) DEFAULT '' COMMENT '版主ID列表（逗号分隔）',
  `created_at` INT UNSIGNED NOT NULL COMMENT '创建时间',
  `updated_at` INT UNSIGNED DEFAULT 0 COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_forums_parent_id` (`parent_id`),
  KEY `idx_forums_rank` (`rank`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='板块表';
```

**设计说明：**
- `parent_id` 支持多级板块分类
- `rank` 用于自定义排序
- `threads`、`posts` 冗余字段，提升查询性能
- `moderators` 存储版主 ID，避免额外关联表

### 3.2.4 帖子表 (threads)

```sql
CREATE TABLE `threads` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '帖子ID',
  `forum_id` INT UNSIGNED NOT NULL COMMENT '板块ID',
  `user_id` INT UNSIGNED NOT NULL COMMENT '发帖用户ID',
  `username` VARCHAR(32) NOT NULL COMMENT '用户名（冗余）',
  `title` VARCHAR(100) NOT NULL COMMENT '帖子标题',
  `views` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '浏览次数',
  `posts` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '回复数',
  `is_top` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否置顶',
  `is_elite` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否加精',
  `is_locked` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否锁定',
  `last_post_user_id` INT UNSIGNED DEFAULT 0 COMMENT '最后回复用户ID',
  `last_post_time` INT UNSIGNED DEFAULT 0 COMMENT '最后回复时间',
  `created_at` INT UNSIGNED NOT NULL COMMENT '创建时间',
  `updated_at` INT UNSIGNED DEFAULT 0 COMMENT '更新时间',
  `deleted_at` INT UNSIGNED DEFAULT NULL COMMENT '删除时间（软删除）',
  PRIMARY KEY (`id`),
  KEY `idx_threads_forum_id` (`forum_id`, `is_top`, `last_post_time`),
  KEY `idx_threads_user_id` (`user_id`),
  KEY `idx_threads_last_post_time` (`last_post_time`),
  FULLTEXT KEY `ft_threads_title` (`title`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='帖子表';
```

**设计说明：**
- `username` 冗余字段，避免每次查询都关联用户表
- `last_post_user_id` 和 `last_post_time` 用于列表排序
- 复合索引 `(forum_id, is_top, last_post_time)` 优化板块列表查询
- 全文索引 `ft_threads_title` 支持标题搜索

### 3.2.5 回复表 (posts)

```sql

  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '回复ID',
  `thread_id` INT UNSIGNED NOT NULL COMMENT '帖子ID',

  `created_at` INT UNSIGNED NOT NULL COMMENT '创建时间',

  `deleted_at` INT UNSIGNED DEFAULT NULL COMMENT '删除时间（软删除）',
  PRIMARY KEY (`id`),
  KEY `idx_posts_thread_id` (`thread_id`, `floor`),
  KEY `idx_posts_user_id` (`user_id`),
  FULLTEXT KEY `ft_posts_content` (`content`)
```

**设计说明：**
- `floor` 楼层号，方便定位和引用
- `content_format` 支持多种内容格式
- 复合索引 `(thread_id, floor)` 优化帖子详情查询
- 全文索引 `ft_posts_content` 支持内容搜索

## 3.3 索引优化策略

### 3.3.1 索引设计原则
1. **高频查询字段**：WHERE、ORDER BY、GROUP BY 中的字段
2. **复合索引顺序**：区分度高的字段在前
3. **覆盖索引**：SELECT 字段包含在索引中，避免回表
4. **避免过多索引**：每个索引都会增加写入成本

### 3.3.2 关键查询优化

#### 板块帖子列表查询
```sql
-- 查询语句
SELECT * FROM threads
WHERE forum_id = ? AND deleted_at IS NULL
ORDER BY is_top DESC, last_post_time DESC
LIMIT 20;

-- 优化索引
KEY `idx_threads_forum_id` (`forum_id`, `is_top`, `last_post_time`)
```

#### 用户未读通知查询
```sql
-- 查询语句
SELECT * FROM notifications
WHERE user_id = ? AND is_read = 0
ORDER BY created_at DESC
LIMIT 10;

-- 优化索引
KEY `idx_notifications_user_id` (`user_id`, `is_read`, `created_at`)
```

#### 全文搜索查询
```sql
-- 查询语句
SELECT * FROM threads
WHERE MATCH(title) AGAINST(? IN BOOLEAN MODE)
AND deleted_at IS NULL
LIMIT 20;

-- 优化索引
FULLTEXT KEY `ft_threads_title` (`title`)
```

## 3.4 分表策略

### 3.4.1 大表分表方案

#### 回复表分表（按帖子ID哈希）
```sql
-- posts_0 到 posts_9（10张表）
CREATE TABLE `posts_0` LIKE `posts`;
CREATE TABLE `posts_1` LIKE `posts`;
-- ... 以此类推

-- 路由规则：thread_id % 10
```

#### 日志表分表（按时间分表）
```sql
-- logs_202601, logs_202602 等（按月分表）
CREATE TABLE `logs_202601` LIKE `logs`;
CREATE TABLE `logs_202602` LIKE `logs`;
```

### 3.4.2 历史数据归档

```sql
-- 归档1年前的日志数据
CREATE TABLE `logs_archive` LIKE `logs`;

INSERT INTO `logs_archive`
SELECT * FROM `logs`
WHERE created_at < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 1 YEAR));

DELETE FROM `logs`
WHERE created_at < UNIX_TIMESTAMP(DATE_SUB(NOW(), INTERVAL 1 YEAR));
```

## 3.5 数据库配置优化

### 3.5.1 MySQL 配置（my.cnf）

```ini
[mysqld]
# 基础配置
default-storage-engine = InnoDB
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci

# InnoDB 配置
innodb_buffer_pool_size = 2G          # 设置为物理内存的 50-70%
innodb_log_file_size = 256M
innodb_flush_log_at_trx_commit = 2    # 性能优化（可接受少量数据丢失）
innodb_flush_method = O_DIRECT

# 查询缓存（MySQL 5.7）
query_cache_type = 1
query_cache_size = 128M

# 连接配置
max_connections = 500
max_connect_errors = 1000

# 慢查询日志
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 0.5                 # 记录超过 500ms 的查询
```

## 3.6 数据迁移脚本

### 3.6.1 初始化脚本

```php
<?php
// install/database.php

$tables = [
    'users' => file_get_contents(__DIR__ . '/sql/users.sql'),
    'forums' => file_get_contents(__DIR__ . '/sql/forums.sql'),
    'threads' => file_get_contents(__DIR__ . '/sql/threads.sql'),
    // ... 其他表
];

foreach ($tables as $table => $sql) {
    try {
        Database::execute($sql);
        echo "✓ 创建表 {$table} 成功\n";
    } catch (Exception $e) {
        echo "✗ 创建表 {$table} 失败: {$e->getMessage()}\n";
    }
}
```

### 3.6.2 数据备份脚本

```bash
#!/bin/bash
# backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backup/mysql"
DB_NAME="amubbs"

# 备份数据库
mysqldump -u root -p${DB_PASSWORD} \
  --single-transaction \
  --quick \
  --lock-tables=false \
  ${DB_NAME} | gzip > ${BACKUP_DIR}/${DB_NAME}_${DATE}.sql.gz

# 删除 7 天前的备份
find ${BACKUP_DIR} -name "*.sql.gz" -mtime +7 -delete
```
