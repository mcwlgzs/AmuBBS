# 插件开发指南

## 10.1 快速开始

### 10.1.1 插件命名规范

⚠️ 插件名称必须使用 **PascalCase**（大驼峰），且目录名、文件名、类名严格对应：

| 项目 | 规则 | 示例 |
|------|------|------|
| 目录名 | `plugins/{Name}/` | `plugins/HelloWorld/` |
| 主文件 | `{Name}Plugin.php` | `HelloWorldPlugin.php` |
| 类名 | `{Name}Plugin` | `HelloWorldPlugin` |
| 命名空间 | `Plugins\{Name}` | `Plugins\HelloWorld` |
| `getName()` 返回值 | 与目录名一致 | `'HelloWorld'` |

加载器 `PluginLoader` 会自动扫描 `plugins/` 下的子目录，按以下规则查找插件：

```
plugins/{Name}/{Name}Plugin.php → 类 Plugins\{Name}\{Name}Plugin
```

如果目录名、文件名、类名不匹配，插件将无法加载。

### 10.1.2 创建第一个插件

**步骤 1：创建目录和主文件**

```php
<?php
// plugins/HelloWorld/HelloWorldPlugin.php

namespace Plugins\HelloWorld;

use Core\Plugin;
use Core\Event;
use App\Events\Events;

class HelloWorldPlugin extends Plugin
{
    public function getName(): string { return 'HelloWorld'; }
    public function getVersion(): string { return '1.0.0'; }
    public function getDescription(): string { return '这是一个示例插件'; }
    public function getAuthor(): string { return '你的名字'; }

    /**
     * 注册服务（在插件启动前调用）
     */
    public function register(): void
    {
        // 注册服务到容器
        // $this->container->singleton(MyService::class, fn() => new MyService());
    }

    /**
     * 启动插件（在所有插件注册完成后调用）
     */
    public function boot(): void
    {
        // 监听事件
        Event::listen(Events::THREAD_CREATED, function (array $payload) {
            $threadId = $payload['thread_id'] ?? 0;
            error_log("HelloWorld: 新帖子创建 #{$threadId}");
        });
    }
}
```

**步骤 2：创建插件信息文件**

```json
// plugins/HelloWorld/plugin.json
{
  "name": "HelloWorld",
  "version": "1.0.0",
  "description": "Hello World 示例插件",
  "author": "你的名字",
  "homepage": "https://example.com",
  "license": "MIT",
  "require": {
    "php": ">=8.2"
  }
}
```

**步骤 3（可选）：创建默认配置**

```php
<?php
// plugins/HelloWorld/config.php

return [
    'enabled' => true,
    'message' => 'Hello World!',
];
```

**步骤 4：启用插件**

在后台管理面板 `/admin/plugins` 中安装并启用插件，或手动编辑 `storage/plugins.json`：

```json
["HelloWorld"]
```

### 10.1.3 插件目录结构

```
plugins/HelloWorld/
├── HelloWorldPlugin.php    # 插件主文件（必需）
├── plugin.json             # 插件信息（必需）
├── config.php              # 默认配置（可选）
├── README.md               # 说明文档（推荐）
├── Services/               # 服务类
│   └── HelloService.php
├── Controllers/            # 控制器
│   └── HelloController.php
├── Views/                  # 视图文件
│   └── hello.php
└── assets/                 # 静态资源（通过 /plugin-assets/ 路由访问）
    ├── css/
    ├── js/
    └── images/
```

## 10.2 核心概念

### 10.2.1 插件生命周期

```
1. 加载 (Load)     — PluginLoader 扫描目录，require 主文件，实例化插件类
                      构造函数中自动加载 config.php + storage/plugin_config/ 覆盖配置
   ↓
2. 注册 (Register) — 调用 register()，注册服务到容器
                      此时其他插件可能尚未注册，不要在这里依赖其他插件
   ↓
3. 启动 (Boot)     — 所有插件注册完成后，对已启用的插件调用 boot()
                      在这里监听事件、注册路由、注册内容过滤器
   ↓
4. 运行 (Running)  — 响应事件和请求
```

**安装/卸载/启用/禁用** 是独立的管理操作，通过后台 `/admin/plugins` 触发：

| 方法 | 触发时机 | 典型用途 |
|------|---------|---------|
| `install()` | 后台点击"安装" | 创建数据表、初始化数据 |
| `uninstall()` | 后台点击"卸载" | 删除数据表、清理文件 |
| `enable()` | 后台点击"启用" | 返回 true 允许启用 |
| `disable()` | 后台点击"禁用" | 返回 true 允许禁用 |

### 10.2.2 插件接口（PluginInterface）

所有插件必须实现 `Core\PluginInterface`，继承 `Core\Plugin` 基类可获得默认实现：

```php
interface PluginInterface
{
    public function getName(): string;        // 必须实现
    public function getVersion(): string;     // 必须实现
    public function getDescription(): string; // 基类返回 ''
    public function getAuthor(): string;      // 基类返回 ''
    public function getDependencies(): array; // 基类返回 []
    public function register(): void;         // 基类空实现
    public function boot(): void;             // 基类空实现
    public function getConfig(): array;       // 基类返回 $this->config
    public function install(): bool;          // 基类返回 true
    public function uninstall(): bool;        // 基类返回 true
    public function enable(): bool;           // 基类返回 true
    public function disable(): bool;          // 基类返回 true
}
```

### 10.2.3 Plugin 基类提供的能力

继承 `Core\Plugin` 后，你可以使用以下 protected 属性和方法：

```php
// 属性
$this->container;   // Core\Container 依赖注入容器
$this->events;      // Core\EventDispatcher 事件分发器实例
$this->config;      // array 插件配置（config.php + 持久化覆盖）

// 方法
$this->listen($event, $callback, $priority);  // 通过 EventDispatcher 监听事件
$this->fire($eventObject);                    // 通过 EventDispatcher 触发事件对象
$this->make(ClassName::class);                // 从容器解析服务
$this->getPluginPath();                       // 获取插件目录绝对路径
$this->getConfig();                           // 获取插件配置数组
```

⚠️ 基类 **不提供** `renderView()`、`jsonResponse()`、`getCurrentUserId()` 等方法。如需这些功能，请在插件中自行实现（参见 10.4 实战示例）。

### 10.2.4 事件系统

AMuBBS 有两套事件机制，插件开发中都可以使用：

**方式一：`Core\Event` 静态类（推荐）**

这是实际项目中使用最多的方式，所有内置插件（AutoAvatar、Emoji 等）都使用这种方式：

```php
use Core\Event;
use App\Events\Events;

public function boot(): void
{
    // 监听事件（payload 是关联数组）
    Event::listen(Events::USER_REGISTERED, function (array $payload) {
        $userId = $payload['user_id'] ?? 0;
        // 处理逻辑
    });

    // 设置优先级（数字越大越先执行）
    Event::listen(Events::THREAD_CREATED, function (array $payload) {
        // 高优先级处理
    }, 100);

    // 监听器返回 false 可阻止后续监听器执行
    Event::listen(Events::POST_CREATED, function (array $payload) {
        if ($this->shouldBlock($payload)) {
            return false; // 停止事件传播
        }
    });
}
```

触发事件（通常由系统触发，插件也可以触发自定义事件）：

```php
Event::dispatch('myplugin.custom_event', ['key' => 'value']);
```

**方式二：`EventDispatcher` 实例（通过基类方法）**

```php
public function boot(): void
{
    // 精确匹配监听
    $this->listen('some.event', function ($payload) {
        // 处理逻辑
    }, $priority);

    // 触发事件对象
    $this->fire(new SomeEventObject());
}
```

如需通配符监听，直接使用 `EventDispatcher` 实例：

```php
public function boot(): void
{
    // 通配符监听（匹配所有 thread.* 事件）
    $this->events->listenWildcard('thread.*', function ($payload) {
        // 处理所有 thread 相关事件
    });
}
```

### 10.2.6 依赖注入

```php
public function register(): void
{
    // 单例模式（整个请求生命周期只创建一次）
    $this->container->singleton(EmailService::class, function ($container) {
        return new EmailService($this->config);
    });

    // 每次解析创建新实例
    $this->container->bind(LogService::class, function ($container) {
        return new LogService();
    });
}

public function boot(): void
{
    // 从容器解析服务
    $emailService = $this->make(EmailService::class);

    // 容器支持构造函数自动注入：如果类的构造函数参数有类型提示，
    // 容器会自动递归解析依赖
}
```

### 10.2.7 插件依赖

如果你的插件依赖其他插件，重写 `getDependencies()` 方法：

```php
public function getDependencies(): array
{
    return ['AutoAvatar', 'Emoji']; // 依赖的插件 getName() 返回值
}
```

`PluginManager` 在注册时会检查依赖，如果被依赖的插件未注册，会抛出异常。

## 10.3 常用功能

### 10.3.1 数据库操作

```php
use Core\Database;

// 查询单条记录（返回关联数组或 null）
$user = Database::fetchOne(
    "SELECT * FROM users WHERE id = ?",
    [$userId]
);

// 查询多条记录（返回关联数组的数组）
$threads = Database::fetchAll(
    "SELECT * FROM threads WHERE forum_id = ? ORDER BY id DESC LIMIT ?",
    [$forumId, 20]
);

// 插入数据
Database::execute(
    "INSERT INTO my_table (name, created_at) VALUES (?, ?)",
    [$name, time()]
);

// 获取最后插入的 ID
$id = Database::lastInsertId();

// 更新数据
Database::execute(
    "UPDATE my_table SET views = views + 1 WHERE id = ?",
    [$id]
);

// 删除数据
Database::execute(
    "DELETE FROM my_table WHERE id = ?",
    [$id]
);

// 事务处理
Database::transaction(function () use ($data) {
    Database::execute("INSERT INTO ...", [...]);
    Database::execute("UPDATE ...", [...]);
    // 抛出异常会自动回滚
});

// 读写分离：读操作使用从库
$result = Database::getReadConnection()->query("SELECT ...");
```

⚠️ 所有时间字段使用 **Unix 时间戳**（`INT UNSIGNED`），不要使用 `DATETIME`。

### 10.3.2 缓存操作

```php
use Core\Cache;

// 获取缓存（不存在返回 null）
$value = Cache::get('my_key');

// 获取缓存，不存在则执行回调并缓存结果
$value = Cache::get('my_key', function () {
    return Database::fetchOne("SELECT ...");
}, 3600); // TTL 3600 秒

// 设置缓存
Cache::set('my_key', $value, 3600);

// 原子设置：仅当 key 不存在时才设置（类似 SETNX）
$locked = Cache::add('lock:task', 1, 60); // 成功返回 true

// 删除缓存
Cache::delete('my_key');

// 批量删除（支持 * 通配符）
Cache::deletePattern('thread:*');
```

缓存采用三级架构：L1 进程内数组 → L2 Redis → L3 回调函数。Redis 不可用时自动降级到进程内缓存。

⚠️ `Cache` 类 **没有** `tags()` 方法。如需按前缀批量清除，使用 `Cache::deletePattern()`。

### 10.3.4 路由注册

```php
use Core\Router;

public function boot(): void
{
    $router = $this->make(Router::class);

    // GET 路由
    $router->get('/hello', function () {
        echo 'Hello World!';
    });

    // POST 路由，指向控制器方法
    $router->post('/hello', [HelloController::class, 'store']);

    // 带动态参数的路由
    $router->get('/hello/{id}', function ($id) {
        echo "Hello #{$id}!";
    });

    // 带中间件的路由（中间件是对象实例，不是字符串）
    $auth = new \App\Middlewares\Auth();
    $router->get('/hello/admin', [HelloController::class, 'index'], [$auth]);
}
```

⚠️ 中间件参数是 `\App\Middlewares\Middleware` 接口的实例数组，不是字符串。

### 10.3.5 Markdown 内容过滤器

插件可以通过 `Markdown::addFilter()` 注册内容过滤器，在 Markdown 渲染为 HTML 后执行。这是修改帖子/回复内容展示的推荐方式：

```php
use Core\Markdown;

public function boot(): void
{
    Markdown::addFilter(function (string $html): string {
        // $html 是已渲染的 HTML 内容
        // 返回处理后的 HTML
        return str_replace(':custom:', '🎯', $html);
    });
}
```

过滤器在以下时机执行：
- `Markdown::parse()` 解析原始 Markdown 后
- `Markdown::render()` 对预渲染内容也会应用过滤器

参考 Emoji 插件的实现：它通过正则匹配 `:name:` 短代码，替换为 Unicode Emoji，同时跳过 HTML 标签内部的内容避免破坏标签属性。

### 10.3.6 插件静态资源

插件的 `assets/` 目录下的文件可通过以下 URL 访问：

```
/plugin-assets/{PluginName}/{filename}
```

例如：`/plugin-assets/AutoAvatar/avatar01.png`

支持的文件类型：`png`、`jpg`、`jpeg`、`gif`、`webp`、`svg`、`css`、`js`

在视图中引用：

```html
<img src="/plugin-assets/HelloWorld/logo.png" alt="Logo">
<link rel="stylesheet" href="/plugin-assets/HelloWorld/css/style.css">
<script src="/plugin-assets/HelloWorld/js/app.js"></script>
```

⚠️ 插件名只允许字母、数字、下划线和连字符，文件路径不允许 `..`（防止目录穿越）。

### 10.3.7 视图渲染（自行实现）

Plugin 基类不提供视图渲染方法，需要在插件中自行实现：

```php
protected function renderView(string $view, array $data = []): void
{
    $viewFile = $this->getPluginPath() . '/Views/' . $view . '.php';

    if (!file_exists($viewFile)) {
        throw new \Exception("视图文件不存在: {$viewFile}");
    }

    extract($data);
    require $viewFile;
}

protected function jsonResponse(array $data): void
{
    header('Content-Type: application/json; charset=utf-8');
    echo json_encode($data, JSON_UNESCAPED_UNICODE);
    exit;
}
```

## 10.4 实战示例：参考内置插件

以下是 AMuBBS 内置的三个插件，展示了不同的插件开发模式。

### 10.4.1 AutoAvatar 插件 — 事件监听模式

监听用户注册事件，自动分配随机头像：

```php
namespace Plugins\AutoAvatar;

use Core\Plugin;
use Core\Database;
use Core\Event;
use App\Events\Events;

class AutoAvatarPlugin extends Plugin
{
    public function getName(): string { return 'AutoAvatar'; }
    public function getVersion(): string { return '1.0.0'; }
    public function getDescription(): string { return '用户注册时自动分配随机头像'; }
    public function getAuthor(): string { return 'AMuBBS'; }

    public function boot(): void
    {
        // 监听用户注册事件
        Event::listen(Events::USER_REGISTERED, function (array $payload) {
            $this->assignRandomAvatar($payload['user_id'] ?? 0);
        });

        // 监听后台添加用户事件
        Event::listen(Events::ADMIN_USER_UPDATED, function (array $payload) {
            if (($payload['action'] ?? '') === '添加用户') {
                $this->assignRandomAvatar($payload['target_id'] ?? 0);
            }
        });
    }

    private function assignRandomAvatar(int $userId): void
    {
        if ($userId <= 0) return;

        $avatars = $this->getAvatarList();
        if (empty($avatars)) return;

        $chosen = $avatars[array_rand($avatars)];
        // 使用插件静态资源路由
        $avatarUrl = '/plugin-assets/AutoAvatar/' . $chosen;
        Database::execute("UPDATE users SET avatar = ? WHERE id = ?", [$avatarUrl, $userId]);
    }

    private function getAvatarList(): array
    {
        // 扫描 assets/ 目录下的图片文件
        $dir = $this->getPluginPath() . '/assets/';
        if (!is_dir($dir)) return [];

        $list = [];
        foreach (scandir($dir) as $file) {
            $ext = strtolower(pathinfo($file, PATHINFO_EXTENSION));
            if (in_array($ext, ['png', 'jpg', 'jpeg', 'gif', 'webp'])) {
                $list[] = $file;
            }
        }
        return $list;
    }

    public function install(): bool
    {
        // 安装时为所有无头像用户补上随机头像
        $users = Database::fetchAll(
            "SELECT id FROM users WHERE avatar IS NULL OR avatar = '' OR avatar = '/assets/images/default-avatar.png'"
        );
        foreach ($users as $user) {
            $this->assignRandomAvatar((int)$user['id']);
        }
        return true;
    }
}
```

**要点：**
- 使用 `Event::listen()` 静态方法监听系统事件
- 事件 payload 是关联数组
- 通过 `/plugin-assets/` 路由引用插件内的静态资源
- `install()` 中可执行一次性初始化逻辑

### 10.4.2 Emoji 插件 — 内容过滤器模式

通过 `Markdown::addFilter()` 注册内容过滤器，将 `:name:` 短代码转换为 Emoji：

```php
namespace Plugins\Emoji;

use Core\Plugin;
use Core\Markdown;

class EmojiPlugin extends Plugin
{
    public function getName(): string { return 'Emoji'; }
    public function getVersion(): string { return '1.0.0'; }
    public function getDescription(): string { return 'Emoji 表情短代码插件'; }
    public function getAuthor(): string { return 'AMuBBS'; }

    private const EMOJI_MAP = [
        'smile' => '😀', 'laugh' => '😂', 'heart' => '❤️',
        'fire'  => '🔥', 'star'  => '⭐', 'rocket' => '🚀',
        // ... 完整映射表见源码
    ];

    public function boot(): void
    {
        // 检查配置开关
        if (!($this->config['enable_shortcode'] ?? true)) return;

        // 注册 Markdown 内容过滤器
        Markdown::addFilter(function (string $html): string {
            return $this->replaceEmoji($html);
        });
    }

    private function replaceEmoji(string $html): string
    {
        $map = self::EMOJI_MAP;

        // 匹配 HTML 标签或 :emoji_name: 短代码
        // HTML 标签原样返回，短代码做替换
        return preg_replace_callback(
            '/(<[^>]*>)|:([a-z_0-9]+):/i',
            function ($m) use ($map) {
                if (!empty($m[1])) return $m[1]; // HTML 标签原样保留
                $name = strtolower($m[2]);
                return $map[$name] ?? $m[0]; // 未知短代码原样返回
            },
            $html
        );
    }
}
```

**要点：**
- 使用 `Markdown::addFilter()` 注册内容过滤器
- 过滤器接收 HTML 字符串，返回处理后的 HTML
- 注意跳过 HTML 标签内部的内容，避免破坏标签属性
- 可通过 `$this->config` 读取配置控制行为

### 10.4.3 SocialLogin 插件 — 服务注册 + 路由模式

社交登录插件展示了完整的 `register()` + `boot()` 分离模式：

```php
namespace Plugins\SocialLogin;

use Core\Plugin;
use Plugins\SocialLogin\Providers\GitHubProvider;

class SocialLoginPlugin extends Plugin
{
    private ?SocialLoginManager $manager = null;

    public function getName(): string { return 'SocialLogin'; }
    public function getVersion(): string { return '1.0.0'; }
    public function getDescription(): string { return '社交账号登录，支持 GitHub/Google/微信/QQ'; }
    public function getAuthor(): string { return 'AMuBBS'; }

    /**
     * register() 阶段：初始化服务，注册到容器
     */
    public function register(): void
    {
        $this->manager = new SocialLoginManager($this->config);

        // 根据配置注册 OAuth 提供者
        $providers = $this->config['providers'] ?? [];
        if (!empty($providers['github']['enabled'])) {
            $this->manager->addProvider(new GitHubProvider($providers['github']));
        }
        // ... 其他提供者

        // 注册到容器，其他代码可通过容器获取
        $this->container->singleton(SocialLoginManager::class, fn() => $this->manager);
    }

    /**
     * boot() 阶段：监听事件
     */
    public function boot(): void
    {
        $this->listen('auth.modal.render', function () {
            return $this->getEnabledProviderData();
        });
    }

    /**
     * 安装时创建数据表
     */
    public function install(): bool
    {
        \Core\Database::execute("
            CREATE TABLE IF NOT EXISTS social_logins (
                id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
                user_id INT UNSIGNED NOT NULL,
                provider VARCHAR(32) NOT NULL,
                open_id VARCHAR(128) NOT NULL,
                nickname VARCHAR(64) NOT NULL DEFAULT '',
                avatar VARCHAR(512) NOT NULL DEFAULT '',
                created_at INT UNSIGNED NOT NULL DEFAULT 0,
                UNIQUE KEY uk_provider_openid (provider, open_id),
                KEY idx_user_id (user_id)
            ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4
        ");
        return true;
    }

    public function uninstall(): bool
    {
        \Core\Database::execute("DROP TABLE IF EXISTS social_logins");
        return true;
    }
}
```

**要点：**
- `register()` 中初始化服务并注册到容器，`boot()` 中监听事件
- 使用 `$this->container->singleton()` 注册单例服务
- `install()`/`uninstall()` 管理数据表生命周期
- 复杂插件可拆分为多个类文件（Provider、Manager 等），自动加载器会处理 `Plugins\` 命名空间

## 10.5 开发注意事项

### 10.5.1 命名空间与自动加载

系统自动加载器映射了 `Plugins\` 命名空间到 `plugins/` 目录：

```
Plugins\HelloWorld\HelloWorldPlugin  → plugins/HelloWorld/HelloWorldPlugin.php
Plugins\HelloWorld\Services\FooSvc   → plugins/HelloWorld/Services/FooSvc.php
```

你的插件内所有类都应使用 `Plugins\{PluginName}\` 命名空间前缀。

### 10.5.2 配置持久化

后台插件配置页面保存的配置会写入 `storage/plugin_config/{PluginName}.json`，并在加载时自动覆盖 `config.php` 中的默认值（使用 `array_replace_recursive` 深度合并）。

### 10.5.3 安全规范

- 所有用户输入必须使用参数化查询（`?` 占位符），**禁止拼接 SQL**
- 输出到 HTML 时使用 `htmlspecialchars($str, ENT_QUOTES, 'UTF-8')`
- 如需接受富文本，使用 `Core\HtmlSanitizer::sanitize()` 过滤
- POST 请求自动受 CSRF 中间件保护（API 路由除外）
- 敏感操作应检查用户权限（`$_SESSION['group_id']`）

### 10.5.4 数据表规范

- 表名建议加插件前缀，避免与系统表冲突（如 `shop_products`）
- 时间字段统一使用 `INT UNSIGNED`（Unix 时间戳）
- 字符集使用 `utf8mb4`，引擎使用 `InnoDB`
- 在 `install()` 中使用 `CREATE TABLE IF NOT EXISTS`
- 在 `uninstall()` 中使用 `DROP TABLE IF EXISTS`

### 10.5.5 错误处理

- 使用 `error_log()` 记录错误，不要直接 `echo` 或 `die()`
- 用 `try/catch` 包裹可能失败的操作
- `install()`/`uninstall()` 返回 `false` 表示操作失败
