# 从单机到分布式扩展指南

## 11.1 设计原则

### 11.1.1 无状态设计

**核心原则：应用层必须无状态**

```php
<?php
// ❌ 错误：使用本地文件存储 Session
session_start();
$_SESSION['user_id'] = 123;

// ✅ 正确：使用 Redis 存储 Session
$redis = new Redis();
$redis->connect('192.168.1.201', 6379);
$redis->setex('session:' . $sessionId, 7200, json_encode(['user_id' => 123]));
```

**无状态检查清单：**
- ✅ Session 存储在 Redis（不在本地文件）
- ✅ 文件上传到 OSS/NFS（不在本地磁盘）
- ✅ 缓存使用 Redis（不使用 APCu/文件缓存）
- ✅ 日志集中收集（不只写本地文件）

### 11.1.2 配置外部化

```php
<?php
// config/app.php

return [
    // 从环境变量读取配置
    'mode' => env('APP_MODE', 'single'), // single | distributed

    'session' => [
        'driver' => env('SESSION_DRIVER', 'redis'), // file | redis
        'redis' => [
            'host' => env('REDIS_HOST', '127.0.0.1'),
            'port' => env('REDIS_PORT', 6379),
        ],
    ],

    'upload' => [
        'driver' => env('UPLOAD_DRIVER', 'local'), // local | oss | nfs
        'oss' => [
            'endpoint' => env('OSS_ENDPOINT'),
            'bucket' => env('OSS_BUCKET'),
        ],
    ],
];
```

## 11.2 扩展路径

### 11.2.1 阶段一：单机部署（0-1000 日活）

```
┌─────────────────────────────────┐
│      单台服务器 (4C8G)           │
│  ┌──────────────────────────┐   │
│  │  Nginx + PHP-FPM         │   │
│  ├──────────────────────────┤   │
│  │  MySQL 8.0               │   │
│  ├──────────────────────────┤   │
│  │  Redis 7.0               │   │
│  └──────────────────────────┘   │
└─────────────────────────────────┘
```

**配置示例：**

```bash
# .env
APP_MODE=single
SESSION_DRIVER=redis
REDIS_HOST=127.0.0.1
UPLOAD_DRIVER=local
```

**特点：**
- 所有服务在一台机器
- 成本低，部署简单
- 适合初期验证

### 11.2.2 阶段二：数据库分离（1000-5000 日活）

```
┌─────────────────┐      ┌─────────────────┐
│  Web 服务器      │─────→│  数据库服务器    │
│  Nginx+PHP-FPM  │      │  MySQL 8.0      │
│  Redis          │      │                 │
└─────────────────┘      └─────────────────┘
```

**迁移步骤：**

1. **准备数据库服务器**
```bash
# 在新服务器上安装 MySQL
sudo apt install mysql-server-8.0

# 配置允许远程连接
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf
# bind-address = 0.0.0.0

# 创建远程用户
mysql -u root -p
CREATE USER 'amubbs'@'%' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON amubbs.* TO 'amubbs'@'%';
FLUSH PRIVILEGES;
```

2. **导出数据**
```bash
# 在原服务器上导出
mysqldump -u root -p amubbs > amubbs_backup.sql

# 传输到新服务器
scp amubbs_backup.sql user@192.168.1.201:/tmp/
```

3. **导入数据**
```bash
# 在新服务器上导入
mysql -u root -p amubbs < /tmp/amubbs_backup.sql
```

4. **修改配置**
```bash
# Web 服务器 .env
DB_HOST=192.168.1.201
DB_PORT=3306
DB_DATABASE=amubbs
DB_USERNAME=amubbs
DB_PASSWORD=password
```

5. **测试连接**
```bash
# 测试数据库连接
php -r "
\$pdo = new PDO('mysql:host=192.168.1.201;dbname=amubbs', 'amubbs', 'password');
echo 'Connected successfully';
"
```

```

                │   负载均衡器     │
                │   Nginx/LVS     │
                └────────┬────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
┌───────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
│ Web 节点 1    │ │ Web 节点 2   │ │ Web 节点 3   │
│ Nginx+PHP    │ │ Nginx+PHP   │ │ Nginx+PHP   │
└───────┬──────┘ └──────┬──────┘ └──────┬──────┘
        │                │                │
        └────────────────┼────────────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
┌───────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
│ MySQL 主库    │ │ Redis 集群  │ │ NFS/OSS     │
└──────────────┘ └─────────────┘ └─────────────┘
```

**迁移步骤：**

**1. 配置文件存储（NFS 或 OSS）**

```bash
# 方案 A：使用 NFS
# NFS 服务器
sudo apt install nfs-kernel-server
sudo mkdir -p /data/amubbs/uploads
sudo vim /etc/exports
# /data/amubbs/uploads 192.168.1.0/24(rw,sync,no_root_squash)
sudo systemctl restart nfs-server

# Web 节点挂载
sudo apt install nfs-common
sudo mount -t nfs 192.168.1.200:/data/amubbs/uploads /var/www/amubbs/public/uploads

# 开机自动挂载
sudo vim /etc/fstab
# 192.168.1.200:/data/amubbs/uploads /var/www/amubbs/public/uploads nfs defaults 0 0
```

```php
<?php
// 方案 B：使用阿里云 OSS
// .env
UPLOAD_DRIVER=oss
OSS_ENDPOINT=oss-cn-hangzhou.aliyuncs.com
OSS_BUCKET=amubbs-uploads
OSS_ACCESS_KEY=your_key
OSS_SECRET_KEY=your_secret
```

**2. 配置 Session 共享（Redis）**

```php
<?php
// config/session.php
return [
    'driver' => 'redis',
    'redis' => [
        'host' => '192.168.1.201',
        'port' => 6379,
        'database' => 1,
    ],
];
```

**3. 部署多个 Web 节点**

```bash
# 在每个 Web 节点上
git clone https://github.com/your-repo/amubbs.git
cd amubbs
composer install --no-dev
cp .env.example .env

# 配置相同的 .env（指向同一个数据库和 Redis）
vim .env
```

**4. 配置负载均衡器**

```nginx
# /etc/nginx/nginx.conf

upstream web_backend {
    # 负载均衡算法
    ip_hash;  # 使用 IP 哈希保持会话（如果用 Redis Session 可以用 least_conn）

    server 192.168.1.101:80 weight=3 max_fails=3 fail_timeout=30s;
    server 192.168.1.102:80 weight=2 max_fails=3 fail_timeout=30s;
    server 192.168.1.103:80 weight=1 max_fails=3 fail_timeout=30s;

    keepalive 32;
}

server {
    listen 80;
    server_name amubbs.com;

    location / {
        proxy_pass http://web_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # 健康检查
        proxy_next_upstream error timeout http_500 http_502 http_503;
    }
}
```

**5. 验证分布式部署**

```bash
# 测试负载均衡
for i in {1..10}; do
    curl -I http://amubbs.com
done

# 检查 Session 共享
# 登录后访问不同节点，确认登录状态保持
```

### 11.2.4 阶段四：数据库读写分离（10000+ 日活）

```
                ┌─────────────────┐
                │   负载均衡器     │
                └────────┬────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
┌───────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
│ Web 节点 1    │ │ Web 节点 2   │ │ Web 节点 3   │
└───────┬──────┘ └──────┬──────┘ └──────┬──────┘
        │                │                │
        └────────────────┼────────────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
┌───────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
│ MySQL 主库    │ │ MySQL 从库1  │ │ MySQL 从库2  │
│ (写)         │ │ (读)        │ │ (读)        │
└──────────────┘ └─────────────┘ └─────────────┘
```

**配置主从复制：**

```bash
# 主库配置 /etc/mysql/mysql.conf.d/mysqld.cnf
[mysqld]
server-id=1
log-bin=mysql-bin
binlog-do-db=amubbs

# 重启 MySQL
sudo systemctl restart mysql

# 创建复制用户
mysql -u root -p
CREATE USER 'repl'@'%' IDENTIFIED BY 'password';
GRANT REPLICATION SLAVE ON *.* TO 'repl'@'%';
FLUSH PRIVILEGES;
SHOW MASTER STATUS;  # 记录 File 和 Position
```

```bash
# 从库配置 /etc/mysql/mysql.conf.d/mysqld.cnf
[mysqld]
server-id=2
relay-log=mysql-relay-bin
read-only=1

# 重启 MySQL
sudo systemctl restart mysql

# 配置主从复制
mysql -u root -p
CHANGE MASTER TO
  MASTER_HOST='192.168.1.201',
  MASTER_USER='repl',
  MASTER_PASSWORD='password',
  MASTER_LOG_FILE='mysql-bin.000001',
  MASTER_LOG_POS=154;

START SLAVE;
SHOW SLAVE STATUS\G  # 检查复制状态
```

**应用层配置：**

```php
<?php
// config/database.php
return [
    'connections' => [
        'mysql' => [
            'write' => [
                'host' => '192.168.1.201', // 主库
            ],
            'read' => [
                ['host' => '192.168.1.202'], // 从库1
                ['host' => '192.168.1.203'], // 从库2
            ],
            'database' => 'amubbs',
            'username' => 'amubbs',
            'password' => 'password',
        ],
    ],

```

### 11.3.1 迁移前检查

```bash
# 1. 备份数据
```

### 11.3.2 迁移步骤

**步骤 1：准备新环境**
```bash
# 在新服务器上安装依赖
sudo apt update
sudo apt install nginx php8.2-fpm php8.2-mysql php8.2-redis
```

**步骤 2：同步代码**
```bash
# 使用 Git 同步
git clone https://github.com/your-repo/amubbs.git
cd amubbs
composer install --no-dev
```

**步骤 3：配置环境变量**
```bash
cp .env.example .env
vim .env
# 修改数据库、Redis 等配置
```

**步骤 4：测试新节点**
```bash
# 单独访问新节点测试
curl http://192.168.1.102/health

# 检查数据库连接
php artisan db:test

# 检查 Redis 连接
php artisan redis:test
```

**步骤 5：加入负载均衡**
```nginx
# 逐步加入新节点
upstream web_backend {
    server 192.168.1.101:80 weight=3;
    server 192.168.1.102:80 weight=1;  # 新节点，先给小权重
}

# 观察一段时间后，调整权重
upstream web_backend {
    server 192.168.1.101:80 weight=2;
    server 192.168.1.102:80 weight=2;  # 权重相同
}
```

**步骤 6：监控验证**
```bash
# 监控错误日志
tail -f /var/log/nginx/error.log
tail -f /var/www/amubbs/storage/logs/app.log

# 监控性能
htop
iostat -x 1
```

### 11.3.3 回滚方案

```bash
# 如果出现问题，立即从负载均衡移除新节点
# 修改 Nginx 配置
upstream web_backend {
    server 192.168.1.101:80;  # 只保留原节点
    # server 192.168.1.102:80;  # 注释掉新节点
}

# 重载 Nginx
sudo nginx -s reload
```

## 11.4 自动化部署脚本

### 11.4.1 一键部署脚本

```bash
#!/bin/bash
# deploy.sh - 自动部署到新节点

set -e

NODE_IP=$1
if [ -z "$NODE_IP" ]; then
    echo "用法: ./deploy.sh <节点IP>"
    exit 1
fi

echo "开始部署到节点: $NODE_IP"

# 1. 同步代码
echo "同步代码..."
rsync -avz --exclude='.git' --exclude='storage' \
    ./ root@$NODE_IP:/var/www/amubbs/

# 2. 同步配置
echo "同步配置..."
scp .env root@$NODE_IP:/var/www/amubbs/

# 3. 安装依赖
echo "安装依赖..."
ssh root@$NODE_IP "cd /var/www/amubbs && composer install --no-dev"

# 4. 设置权限
echo "设置权限..."
ssh root@$NODE_IP "chown -R www-data:www-data /var/www/amubbs"

# 5. 重启服务
echo "重启服务..."
ssh root@$NODE_IP "systemctl reload php8.2-fpm"

# 6. 健康检查
echo "健康检查..."
sleep 3
curl -f http://$NODE_IP/health || {
    echo "健康检查失败！"
    exit 1
}

echo "部署成功！"
```

### 11.4.2 健康检查接口

```php
<?php
// public/health.php

header('Content-Type: application/json');

$health = [
    'status' => 'ok',
    'timestamp' => time(),
    'checks' => [],
];

// 检查数据库
try {
    $pdo = new PDO(
        'mysql:host=' . getenv('DB_HOST') . ';dbname=' . getenv('DB_DATABASE'),
        getenv('DB_USERNAME'),
        getenv('DB_PASSWORD')
    );
    $pdo->query('SELECT 1');
    $health['checks']['database'] = 'ok';
} catch (Exception $e) {
    $health['status'] = 'error';
    $health['checks']['database'] = 'error: ' . $e->getMessage();
}

// 检查 Redis
try {
    $redis = new Redis();
    $redis->connect(getenv('REDIS_HOST'), getenv('REDIS_PORT'));
    $redis->ping();
    $health['checks']['redis'] = 'ok';
} catch (Exception $e) {
    $health['status'] = 'error';
    $health['checks']['redis'] = 'error: ' . $e->getMessage();
}

// 检查磁盘空间
$diskFree = disk_free_space('/');
$diskTotal = disk_total_space('/');
$diskUsage = round((1 - $diskFree / $diskTotal) * 100, 2);
$health['checks']['disk'] = $diskUsage . '%';

if ($diskUsage > 90) {
    $health['status'] = 'warning';
}

http_response_code($health['status'] === 'ok' ? 200 : 500);
echo json_encode($health, JSON_PRETTY_PRINT);
```

## 11.5 常见问题

### Q1: 如何确保 Session 在多节点间共享？
**A:** 使用 Redis 存储 Session，所有节点连接同一个 Redis。

### Q2: 文件上传后其他节点看不到怎么办？
**A:** 使用 NFS 共享存储或 OSS 对象存储。

### Q3: 如何实现零停机部署？
**A:** 使用滚动更新：逐个节点更新，更新时从负载均衡移除。

### Q4: 数据库主从延迟怎么办？
**A:**
- 写操作后立即读取使用主库
- 对实时性要求不高的读取使用从库
- 监控主从延迟，超过阈值告警

### Q5: 如何监控分布式系统？
**A:** 使用 Prometheus + Grafana 监控各节点状态。
